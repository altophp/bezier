# Alto Bezier

Alto Bezier evaluates, measures, splits, and intersects immutable two-dimensional
Bézier curves. It provides dedicated classes for degrees two through five and a
generic curve for any number of control points.

Use the dedicated curve pages to choose the right representation. The shared
operations work the same way across every curve type.
